Egress Guard

Browser privacy

Choose which Chrome settings Egress Guard should manage for this profile. Review the tradeoffs, then apply your choices.

These controls affect the browser profile across sites. Incognito can have separate overrides. They do not install a VPN, hide your public IP address or verify proxy routing.

Reading browser privacy status…

Return profile settings to Chrome

Release removes only Egress Guard’s setting overrides. Chrome then uses your current preferences, other extensions and organization policies. It does not write a saved copy of your old settings.

Read-back values are shown per control. A selected checkbox is a request, not proof that Chrome accepted it. Safe Browsing and password-manager settings are outside this feature.

Limit high-entropy Client Hints · Experimental

This optional control removes eight detailed User-Agent Client Hints from HTTP(S) requests visible to the extension. It also asks Chrome to restrict the document’s high-entropy JavaScript API when the response has no Permissions-Policy header.

Existing Permissions-Policy headers remain untouched. Documents with an existing policy may still expose detailed values to scripts. Worker JavaScript, cached or already-open documents, other extensions and browser-owned traffic have not been qualified. Browser version, operating-system family, IP address and other fingerprinting surfaces remain visible.

Reading installed rules…

Off initially. No additional permission is requested. Reload a page after changing this choice; releasing it cannot undo a policy already attached to an open document. Installed-rule readback does not prove native browser behavior or that fingerprinting has stopped. Sites that choose downloads or compatibility workarounds from detailed UA data may behave differently.

Privacy signals and boundaries

Egress Guard’s request rules send Sec-GPC: 1. Its document script supplies navigator.globalPrivacyControl only where no property already exists. An existing browser value is preserved; worker JavaScript is outside that script. This is an opt-out signal, not proof that a site honors it. Egress Guard does not change Do Not Track.
