## Scope decisions

- Preserve origin TLS and the current proxy/browser division. The proxy is not a machine-wide firewall or an isolation backend.
- Research task-scoped execution separately. Do not ship a proxy-environment wrapper as a secure sandbox. Actual namespace/VM isolation, direct TCP/UDP, filesystem, IPC, inherited-socket and secret-path escape tests are prerequisites.
- Prefer narrowly supported browser-native controls over broad API spoofing or fingerprint farbling.
- Defer Rust/QUIC/Network Extension/hardware approval rewrites until a measured requirement and a qualified environment justify them.
- Signed feed deltas require a concrete signing trust root, bounded authority, replay/rollback rules, quota/readback and recovery. Never substitute an unsigned remote rule loader.
- Keep domain history off by default. Labs use synthetic identifiers and controlled local sinks. Never contact a production collector with generated events.
